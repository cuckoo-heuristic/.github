## Description
### Cuckoo Core
A simulation platform for evaluating and comparing different metaheuristic algorithm V2X and edge-computings [Repository](https://github.com/cuckoo-heuristic/cuckoo-core)

### Cuckoo Library
A library that provides operations for metaheuristic algorithms [Repository](https://github.com/cuckoo-heuristic/cuckoo-library)

### Cuckoo Front
A front-end interface for CUCKOO-CORE simulations and task management [Repository](https://github.com/cuckoo-heuristic/cuckoo-front)
